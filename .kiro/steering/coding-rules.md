# Ory Hydra — Coding Rules

Strict coding standards for this repository. Follow without exception.

## 1. Tech Stack

- Module: `github.com/ory/hydra/v2`, Go 1.26+, Go modules only (no vendoring)
- Local `replace` directives: `github.com/ory/x` → `./oryx`, `github.com/ory/hydra-client-go/v2` → `./internal/httpclient`
- To modify `ory/x` behavior, edit `./oryx/`. Never add external `replace` directives.

### Required Libraries

| Purpose | Library | Rule |
|---|---|---|
| Logging | `github.com/ory/x/logrusx` | Never use `log` or raw `logrus` |
| Configuration | `github.com/ory/x/configx` | Access via `driver/config.DefaultProvider` |
| HTTP errors | `github.com/ory/herodot` | All HTTP errors through `herodot.Writer` |
| Error wrapping | `github.com/pkg/errors` | Always `errors.WithStack()` or `errors.Wrap()`. Never bare `fmt.Errorf` |
| CLI | `github.com/spf13/cobra` | `New*Cmd()` functions returning `*cobra.Command` |
| HTTP routing | `github.com/ory/x/httprouterx` | `RouterPublic` / `RouterAdmin` separation |
| Testing | `github.com/stretchr/testify` | `require` for fatal, `assert` for non-fatal |
| Mocking | `go.uber.org/mock/mockgen` | Via `go tool mockgen`. Mocks in `internal/mock/` or `*_test.go` |
| Tracing | `go.opentelemetry.io/otel` | Via `github.com/ory/x/otelx` |
| Database | `github.com/ory/pop/v6` | Pop ORM for SQL persistence |
| JSON paths | `github.com/tidwall/gjson`, `sjson` | Dynamic JSON access/mutation |
| UUID | `github.com/gofrs/uuid` | Primary UUID library |
| HTTP client | `github.com/hashicorp/go-retryablehttp` | Always use retryable clients from registry |
| Swagger/OpenAPI | `github.com/go-swagger/go-swagger` | Swagger comments generate `spec/swagger.json` |
| OAuth2 core | `github.com/ory/hydra/v2/fosite` | In-tree Fosite fork |
| Property tests | `pgregory.net/rapid` | For property-based testing |

## 2. Package Structure

### Where to Place New Code

| What | Where | Pattern |
|---|---|---|
| New domain | Top-level package (e.g., `credential/`) | Follow `client/` or `consent/` structure |
| HTTP handlers | `<domain>/handler.go` | `Handler` struct with `InternalRegistry` |
| Domain interfaces | `<domain>/manager.go` | `Manager` + `ManagerProvider` interfaces |
| Registry wiring | `<domain>/registry.go` | `Registry` + `InternalRegistry` interfaces |
| Persistence | `persistence/definitions.go` | Compose into `Persister` |
| SQL impl | `persistence/sql/` | Implement `Persister` methods |
| Config keys | `driver/config/provider.go` | `Key*` constants + getters on `DefaultProvider` |
| CLI commands | `cmd/cmd_<verb>_<noun>.go` | `New<Verb><Noun>Cmd()` |
| Fosite extensions | `fositex/` or `fosite/handler/<name>/` | New grant types, token handlers |
| Test helpers | `internal/testhelpers/` | Shared across packages |

### Forbidden

- Never create `util/`, `common/`, `shared/`, or `helpers/` packages
- Never put domain logic in `x/` — cross-cutting infrastructure only
- Never edit `internal/httpclient/` — generated by `make sdk`
- Every domain package must define its own `Registry` interface in `registry.go`
- `driver.RegistrySQL` must satisfy all domain `Registry` interfaces

## 3. Naming Conventions

- Exported: `PascalCase`. Unexported: `camelCase`.
- Acronyms always all-caps: `ID`, `URL`, `HTTP`, `JWT`, `OIDC`, `PKCE`, `CSRF` (both exported and unexported: `clientID`, `requestURL`).
- Package names: short, lowercase, singular nouns (`client`, `consent`, `oauth2`). No underscores or camelCase. Import aliases only on collision.
- Single-method interfaces: `-er` suffix (`Networker`, `Transactor`). Multi-method: descriptive nouns (`Manager`, `Storage`, `Strategy`).
- Always pair with `<Thing>Provider` interface: `type ManagerProvider interface { ConsentManager() Manager }`.
- Handler structs: `Handler` (one per package). Config: `DefaultProvider`. Registry: `RegistrySQL`.
- Files: `handler.go`, `manager.go`, `registry.go`, `strategy.go`, `error.go`, `<noun>.go` for models.
- CLI files: `cmd_<verb>_<noun>.go`. Test helpers: `*_test_helpers.go` or `internal/testhelpers/`.
- Config key constants: `Key<DescriptiveName>`. URL path constants: `<Noun>Path`.
- Add `// #nosec G101` for false-positive secret detection on non-secret constants.

## 4. Go Idioms

### context.Context

- Always first parameter: `func Foo(ctx context.Context, ...) error`. Never store in a struct field.
- Use `t.Context()` in tests (not `context.Background()`).

### Receivers

- Pointer receivers on all methods for mutable/reference-holding structs.
- Short abbreviation: `(m *RegistrySQL)`, `(h *Handler)`, `(p *DefaultProvider)`.
- Consistent within a type — all pointer or all value.

### Struct Initialization

- Named field literals only. Constructor functions: `NewHandler(r InternalRegistry) *Handler`. Never positional initialization.

### Dependency Injection

Manual registry pattern (no DI framework):
- Domain packages define `Registry` + `InternalRegistry` in `registry.go`.
- `InternalRegistry` embeds `Registry` + cross-cutting providers (`logrusx.Provider`, `httpx.WriterProvider`, `otelx.Provider`, etc.).
- `Handler` structs accept `InternalRegistry` in their constructor.
- `driver.RegistrySQL` is the single concrete implementation satisfying all registries.
- Functional options: `type OptionsModifier func(*options)` for registry construction.

### Lazy Initialization

`RegistrySQL` uses nil-check lazy init for expensive dependencies:
```go
func (m *RegistrySQL) Writer() herodot.Writer {
    if m.writer == nil {
        m.writer = herodot.NewJSONWriter(m.Logger())
    }
    return m.writer
}
```

### Formatting

- `goimports` with `--local github.com/ory`. Import order: stdlib → third-party → `github.com/ory/*` → `github.com/ory/hydra/v2`.
- `gofmt` compliance, tabs for indentation. `golangci-lint` with project `.golangci.yml`.

### Copyright Header

Every `.go` file must start with (use current year for new files):
```go
// Copyright © 2026 Ory Corp
// SPDX-License-Identifier: Apache-2.0
```

## 5. Error Handling & Logging

### Error Wrapping

- Always `errors.WithStack(err)` or `errors.Wrap(err, "message")` from `github.com/pkg/errors`. Never bare `fmt.Errorf`. Project does not use `%w`.
- Use `errors.As` / `errors.Is` for type checking.

### Domain Errors

Define as package-level `var` using `fosite.RFC6749Error`:
```go
var ErrInvalidClientMetadata = &fosite.RFC6749Error{
    DescriptionField: "...",
    ErrorField:       "invalid_client_metadata",
    CodeField:        http.StatusBadRequest,
}
```
Chain context with `.WithHint()`, `.WithDebug()`, `.WithDebugf()`, `.WithDescription()`. Cross-cutting errors live in `x/errors.go`.

### Fosite Errors

For OAuth2/OIDC protocol errors, chain from fosite sentinels:
```go
return errors.WithStack(
    fosite.ErrServerError.WithWrap(err).WithDescription("...").WithDebugf("..."),
)
```

### HTTP Responses

All responses through `h.r.Writer()`:
- `h.r.Writer().WriteError(w, r, err)` — errors
- `h.r.Writer().Write(w, r, data)` — success
- `h.r.Writer().WriteCreated(w, r, locationURL, data)` — 201
- `h.r.Writer().WriteCode(w, r, statusCode, data)` — custom status

Never `http.Error()` or manual `json.NewEncoder` for responses.

### Logging

- Structured logger from registry: `reg.Logger()` or `m.l`.
- Context: `.WithError(err)`, `.WithRequest(r)`, `.WithField(key, value)`.
- Levels: `.Errorln()`, `.Warnln()`, `.Infof()`, `.Debugf()`.
- Never `fmt.Println` or `log.Println`. `.Fatalf()` only for unrecoverable startup errors.

## 6. Concurrency

- No global mutable state. All state in `RegistrySQL` or `context.Context`.
- Package-level `var` only for sentinel errors and compile-time checks: `var _ Strategy = (*defaultStrategy)(nil)`.
- Use `golang.org/x/sync/errgroup` for concurrent work. Never bare goroutines without error propagation.
- `sync.RWMutex` for shared resources, `sync.Once` for one-time init.
- Transactions via `Transactor` interface / `persistence.Persister.Transaction()`.

## 7. Testing

- Tests alongside code: `handler_test.go` next to `handler.go`. `_test` package suffix for black-box tests. Shared helpers in `internal/testhelpers/`.
- In-memory registry: `testhelpers.NewRegistryMemory(t)`. SQL: `testhelpers.NewRegistrySQLFromURL(t, dsn, ...)`. HTTP: `httptest.NewServer` with `t.Cleanup(ts.Close)`.
- Call `t.Parallel()` for independent tests.
- `require` for preconditions (fatal). `assert` for test assertions (non-fatal).
- Table-driven tests: `t.Run("case=descriptive name", func(t *testing.T) { ... })`. Always prefix with `case=`.
- Mocks: `go.uber.org/mock/mockgen` via `//go:generate go tool mockgen ...`. Shared in `internal/mock/`, test-specific in `*_mock_test.go`.
- Snapshots: `github.com/bradleyjkemp/cupaloy/v2` in `<package>/.snapshots/`. Update: `UPDATE_SNAPSHOTS=true go test ./...`.
- Quick tests (no DB): `go test -failfast -short ./...`
- Full tests (with DB): `source scripts/test-env.sh && go test -failfast -timeout=20m ./...`

## 8. HTTP Handler Pattern

Every domain package follows this structure:
```go
type Handler struct { r InternalRegistry }
func NewHandler(r InternalRegistry) *Handler { return &Handler{r: r} }
func (h *Handler) SetRoutes(admin *httprouterx.RouterAdmin) { ... }
func (h *Handler) SetPublicRoutes(public *httprouterx.RouterPublic, corsMiddleware func(http.Handler) http.Handler) { ... }
```

- Routes registered in `RegistrySQL.RegisterAdminRoutes()` / `RegisterPublicRoutes()`.
- Admin routes prefixed `/admin` by infrastructure. Public routes have no prefix.
- Path constants at package level: `const ClientsHandlerPath = "/clients"`.
- Handler signature: `func (h *Handler) methodName(w http.ResponseWriter, r *http.Request)`.
- Read body: `json.NewDecoder(r.Body).Decode(&target)`. Write via `h.r.Writer()`.
- Every endpoint must have Swagger annotations (`swagger:route`, `swagger:parameters`, `swagger:model`).

## 9. Configuration

- Schema source of truth: `spec/config.json` (embedded via `//go:embed` in `spec/config.go`). `.schema/config.schema.json` is derived — never edit directly.
- Adding new config: (1) `Key*` constant in `driver/config/provider.go`, (2) getter on `DefaultProvider` with `ctx context.Context` first param, (3) property in `spec/config.json`, (4) run `scripts/render-schemas.sh`.
- Access: always `reg.Config().Method(ctx)`. Never read env vars directly. `DefaultProvider` uses `p.getProvider(ctx)` for multi-tenant support.

## 10. Database & Persistence

- `persistence.Persister` is the aggregate interface composing all domain storage interfaces. `persistence/sql/` is the single SQL implementation using Pop.
- Models: Pop struct tags (`db:"column_name"`), implement `TableName() string`. Use `sqlxx.NullString`/`sqlxx.NullBool` for nullable columns. `BeforeSave(*pop.Connection) error` for pre-persistence logic.
- Migrations in `persistence/sql/migrations/`, sources in `persistence/sql/src/`. Must support PostgreSQL, MySQL, CockroachDB, and SQLite.

## 11. CLI Commands

- Every command: `New*Cmd()` returning `*cobra.Command` with `RunE`.
- Register in `cmd/root.go` via `RegisterCommandRecursive`.
- Use `driver.OptionsModifier` for serve commands, `configx.RegisterFlags(cmd.PersistentFlags())` for config flags.

## 12. Code Generation

- `make sdk` — OpenAPI spec + Go SDK in `internal/httpclient/`. `make mocks` — mock implementations. `make format` — copyright headers, goimports, prettier.
- Never manually edit generated files (`internal/httpclient/`, `internal/mock/`). Always `make format` after generation.
- Mock generation: `go tool mockgen` (Go 1.24+ tool directive).
